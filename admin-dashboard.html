⚡ Fast Delivery (Shiprocket Quick)

Now checked live via Shiprocket — no manual PIN list

Fast Delivery at checkout is no longer a manual PIN code list — it now calls Shiprocket's live Courier Serviceability API for every PIN code a customer enters, using your pickup PIN code 400008 and the cart's real weight, and looks specifically for Shiprocket Quick (same-day/instant delivery) being serviceable there. If Quick is serviceable for that PIN code right now, the customer automatically sees the paid Fast Delivery option — nothing to add or maintain here.

Fast Delivery pricing is now live per PIN code too — the customer sees the exact Shiprocket Quick cost Shiprocket calculates for their specific delivery PIN code and cart weight, not a flat site-wide charge. (If Shiprocket's rate lookup ever fails, checkout falls back to a flat ₹180 under ₹899 / ₹99 at ₹899+ so nothing breaks.) When a Fast Delivery order comes in, book/fulfil it via Shiprocket Quick as usual — select "Shiprocket Quick" as the delivery partner in the Delivery page below.
